Summary Table for Quick Reference
Core Workflows Summary
Iteration (Fastest): Use python main.py --mode summary --reuse-artifacts. This is your "tweak and check" command. It skips data fetching and feature calculation, running only the backtester on existing data to give you an immediate PnL summary.
Validation (Deep Dive): Use python main.py --mode backtest --refresh-data. Use this after making structural changes to your indicators or to sync with the latest market data. Follow up with python main.py --mode stress --stress-random-runs 10 to ensure your strategy isn't "curve-fitted" to a specific time period.
Production (Live):
Preview: python main.py --mode live checks for a signal without taking a trade.
Execute: python main.py --mode live --execute-live is the active trading command that enforces safety filters (spread, score, state) before sending orders to MT5.
Replay (Debugging): Use python main.py --mode replay --replay-start "YYYY-MM-DD". This is essential for "forensic" analysis of specific losses or unusual market behavior.
Efficiency Tips
Reduce Log Noise: Use --log-level WARNING during long backtests to prevent the console from being overwhelmed.
Portfolio Power: Your recent refactor means that in live mode, the system will automatically cycle through all symbols listed in your portfolio configuration.
Continuous Execution: Until a native loop is implemented in the Python code, you can keep the bot running every 5 minutes using shell loops:
PowerShell: while($true) { python main.py --mode live --execute-live; sleep 300 }
Command Prompt: for /l %g in () do (python main.py --mode live --execute-live & timeout /t 300)
This structure ensures you spend less time waiting for data and more time refining the "Elite" logic of your strategy.
