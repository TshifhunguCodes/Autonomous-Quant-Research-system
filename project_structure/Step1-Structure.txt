2. OPERATIONAL EXECUTION GUIDE (ORDER OF USE)
--------------------------------------------------------------------------------

PHASE 1: DATA & RESEARCH (Preparation)
--------------------------------------------------------------------------------
1. Refresh Market Data:
   python main_v3.py --mode research
   > Syncs latest bars and generates the 83-column pipeline.csv artifact.

2. Validation of Pipeline Logic:
   python test_v3_integration.py
   > Checks that all V3 engines are communicating without errors.

PHASE 2: VALIDATION (Historical Testing)
--------------------------------------------------------------------------------
3. Full Backtest:
   python main_v3.py --mode backtest --output data/backtest/v3_research_output.csv
   > Simulates Alpha/Flow systems over historical data.

4. Institutional Readiness Check:
   python validator_institutional.py
   > Runs a 20-point diagnostic on backtest results for go-live approval.

5. Walk-Forward Stability:
   python v3_final_report.py
   > Analyzes consistency and Win Rate degradation across regimes.

PHASE 3: STRESS & FORENSICS (Robustness)
--------------------------------------------------------------------------------
6. Forensic Replay (Debugging):
   python main_v3.py --mode replay --replay-max-candles 1000
   > Simulates live trading candle-by-candle for logic verification.

7. Monte Carlo Analysis:
   Included in 'validator_institutional.py'
   > Tests resilience against sequence reshuffling and spread spikes.

PHASE 4: PRODUCTION (Live Execution)
--------------------------------------------------------------------------------
8. Live Signal Preview:
   python main_v3.py --mode live
   > Real-time monitoring with heartbeats. Will NOT place orders.

9. Active Trading:
   python main_v3.py --mode live --execute
   > Sends orders to MT5 demo if all institutional safety guards pass.

10. Dashboard Monitoring:
   python main_v3.py --mode dashboard
   > Launches the Streamlit UI and Backend API for visual tracking.

3. PRO-TIPS & UTILITIES
--------------------------------------------------------------------------------
* Automation: Use a shell loop for continuous live execution:
  Powershell: while($true) { python main_v3.py --mode live --execute --live-lookback-days 2; sleep 10 }
* Heartbeats: Monitor Telegram for system status and trade alerts.
* Integrity: Always run 'validator_institutional.py' before increasing risk.
