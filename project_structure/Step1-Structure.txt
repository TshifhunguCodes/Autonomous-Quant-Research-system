2. OPERATIONAL EXECUTION GUIDE (ORDER OF USE)
--------------------------------------------------------------------------------

PHASE 1: DATA & RESEARCH (Preparation)
--------------------------------------------------------------------------------
1. Refresh Market Data:
   python main.py --mode research --refresh-data
   > Syncs latest M5/H1 bars from MT5 and rebuilds all technical features.

2. Logic Iteration (No Data Fetch):
   python main.py --mode research --reuse-artifacts
   > Re-calculates signals/setups based on current code using existing data.

PHASE 2: VALIDATION (Historical Testing)
--------------------------------------------------------------------------------
3. Full Backtest:
   python main.py --mode backtest --refresh-data
   > Runs end-to-end: Data -> Features -> Strategy -> Performance Summary.

4. Fast Iteration (Backtest only):
   python main.py --mode summary --reuse-artifacts
   > The "Tweak & Check" command. Runs only the backtester on cached signals.

5. Out-of-Sample (OOS) Validation:
   python main.py --mode backtest --in-sample-end 2024-01-01 --oos-start 2024-02-01
   > Checks for overfitting by testing on data the strategy hasn't "seen".

PHASE 3: STRESS & FORENSICS (Robustness)
--------------------------------------------------------------------------------
6. Robustness Stress Test:
   python main.py --mode stress --stress-random-runs 10 --stress-window-days 5
   > Runs multiple random walk-forward slices to verify consistency.

7. Forensic Replay (Debugging):
   python main.py --mode replay --replay-start "2024-04-01" --replay-max-candles 500
   > Simulates live trading candle-by-candle to debug specific trade decisions.

PHASE 4: PRODUCTION (Live Execution)
--------------------------------------------------------------------------------
8. Live Signal Preview:
   python main.py --mode live --reuse-artifacts
   > Checks current market for signals. Will NOT place orders.

9. Active Trading:
   python main.py --mode live --execute-live
   > Checks for signals and sends orders to MT5 if all safety guards pass.

3. PRO-TIPS & UTILITIES
--------------------------------------------------------------------------------
* Global Override: Use '--log-level DEBUG' for deep tracing of every calculation.
* Rolling Windows: Adjust '--rolling-window-days' to change the size of stability reports.
* Automation: Use a shell loop for continuous live execution:
  Powershell: while($true) { python main.py --mode live --execute-live; sleep 300 }
